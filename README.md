# 🛠️ QMK/ZMK用 JSON 改行整形ツールキット (JSON Format Toolkit for QMK/ZMK)

QMK/ZMK Firmwareのキーコード設定ファイル（JSON）や、JavaScriptファイルに埋め込まれたJSONのパース・差分計算・コンフリクト差分計算を行うためのWebツールキットです。
GitHub Pagesを利用して、ブラウザ上だけで完全に動作します。

* 公開Webサイト: [QMK/ZMK用 JSON 改行整形ツールキット](https://karbou12.github.io/qmk-json-tool/)

---

## 🚀 主な機能

### 1. 🔀 1行 ⇔ 改行整形 相互変換エディタ (VS Code風 行番号付き)
* **QMK特有の構文保護:** 独自アルゴリズムを搭載。一般的なJSONパースでは破壊されがちな、ユニコード、バックスラッシュの連続（`\\`）、末尾のカンマなどを文字単位で完全に退避・保護します。
* **双方向変換:** ミニファイされた1行JSONを展開したり、逆に編集後のJSONを1行（スペースなし）に圧縮してQMKコードへ即座に組み込めます。
* **エディタライクなUI:** 行番号表示およびドラッグによる自在なリサイズに対応。

### 2. 🔍 JS & JSON 差分再計算 (Code Re-Diff)
* **埋め込みJSONの自動大展開:** JavaScriptコードの1行に埋め込まれた巨大な `JSON.parse('...')` を検知すると、自動で複数行にインデント展開してから差分（LCSアルゴリズム）を計算します。
* **スマートフィルタ:** 変更があった前後数行（デフォルト: 3行）だけをスマートに絞り込んで表示します（左右連動スクロール付き）。

### 3. ⚡ コンフリクト　差分再計算ツール (Conflict Resolver)
* **マーカー自動解析:** マージ時に発生した `<<<<<<<`, `=======`, `>>>>>>>` を含むコードをそのまま貼り付けるだけで、「現在の変更(HEAD)」と「取り込みたい変更」に自動で分離します。
* **コード＆JSON両対応:** 1行JSONが含まれるJavaScriptファイルのコンフリクトでも、JSONを展開した綺麗な状態でどちらのコードを取り込むべきか比較できます。

---

## 🛠️ 技術スタック

* **Frontend:** HTML5, CSS3, JavaScript (Vanilla JS)
* **Algorithm:** 最長共通部分系列 (LCS - Longest Common Subsequence) アルゴリズムによる高速な行単位差分検知
* **Theme:** GitHub風のモダンでクリーンなUIデザイン

## 🤖 開発の経緯
筆者はKeychron Nape Proの機能追加のために、Keychron LauncherをGoogle Chrome Developer ToolのOverrideを使って拡張しています。  
Keychron Launcherが更新されるとマージ・コンフリクト解消が必要になりますが、特にキーマップのJSONに差分が生じたときのコンフリクト解消や、キーマップ追加に手間がかかっていたため、
このツールキットを開発しました。  
コアロジックやUI、設計、およびReadMeは、**Google Gemini** との共同開発となります。

## 💻 使い方

1. [公開されているWebサイト](https://karbou12.github.io/qmk-json-tool/)にアクセスします。
2. 上部のタブから使いたいツール（`1行 ⇔ 改行整形` / `JS & JSON 差分再計算` / `コンフリクト解消`）を選択します。
3. テキストエリアに対象のコードやJSONを貼り付け、実行ボタンを押すだけです。

---

## 🔒 セキュリティとプライバシーについて

このツールは **100%クライアントサイド（お使いのブラウザ上）** で動作します。
貼り付けられたソースコードやJSONデータ、機密情報が外部のサーバーに送信されることは一切ありません。完全オフライン環境でも安心してご利用いただけます。
