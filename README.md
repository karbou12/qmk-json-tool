# 🛠️ QMK/ZMK用 JSON 改行整形ツールキット (JSON Format Toolkit for QMK/ZMK)
> **QMKファームウェアのビルド・配信用1行JSONコードの展開、比較、コンフリクト解消、1行部分圧縮までをブラウザ上で完結させる、Webツールキット。**

QMK/ZMKファームウェア（自作キーボード等）のキーコード設定ファイル(JSON, Vilなど)、JavaScriptコード内に埋め込まれた複雑な1行JSON（`JSON.parse('...')`）や、素のJSONデータのGitデプロイ・マージ作業を効率化するために開発しWebツールキットです。  
GitHub Pagesを利用して、ブラウザ上だけで完全に動作します。

* 公開Webサイト: [QMK/ZMK用 JSON 改行整形ツールキット](https://karbou12.github.io/qmk-json-tool/)

---

## 🚀 搭載されている4つのツール（機能概要）

### 1. 🔀 Minified ⇔  Prettified Editor: 1行 ⇔  改行整形 相互変換エディタ
* **100%文字保護：** `\x` や `\u25bd`、エスケープシングルクォート（`\'`）などのQMK/ZMK特有のエスケープ構文を可能な限り保護。
* **双方向変換：** 1行のガチガチなコードをインデント付きの美しい複数行エディタに展開し、手動編集後に再びスペース1文字すら残さない極限のミニファイ1行コードに圧縮します。
* **一般JSON対応：** 一般のWeb開発向けに、コロンやカンマの後に自動で半角スペースを1つ補う「可読性優先スペースオプション」もワンクリックで切り替え可能。

### 2. 🔍 Diff Viewer: JS & JSON 差分再計算マシーン
* **LCSアルゴリズム搭載：** 展開された巨大なJavaScript / JSONのGit diffテキストから、実際の変更行を上から1行ずつ精密に解析・比較。
* **スマート差分絞り込み：** 変更のあった前後数行（コンテキスト行数：1以上の正の整数ガード付き）だけをスマートに切り出し、巨大なファイルでも一瞬で変更点を見つけられます。

### 3. ⚡ Conflict Viewer: コンフリクト表示 (閲覧用)
* Gitのマージコンフリクト（`<<<<<<<`, `=======`, `>>>>>>>`）を自動検知。
* 左右50%の並列ペイン上に、現在の変更（HEAD）と取り込みたい変更（Incoming）を綺麗に並べて差分をマージ前に視覚的にプレビューできます。

### 4. 👑 🚀 Conflict Merge Tool: 1行JSON高度マージエディタ（本ツールの真骨頂）
* **不完全構文の自動救済：** Gitマージミス等で、クォートが片方千切れてしまっている「壊れたJS構文」からでも、内部のJSONデータを強引にむしり取って美しく縦長に大展開します。
* **ワンクリックマージ解決：** `[HEADを採用]` `[Incomingを採用]` `[両方を残す]` ボタンを押すだけで、下段のリアルタイムエディタに解決結果を自動組み立て。手動による高度な追加編集も自由自在です。
* **ピンポイント部分1行圧縮：** 周りのJavaScript構文や改行・インデントは1文字も壊さず、マージ解決した**中のJSON部分だけを狙い撃ちで完璧な1行にギュッと逆圧縮**して出力します。

## 🎨 プロ仕様の極上の操作フィーリング（こだわり抜いたUI/UX）

* **コンパイラ級ステートマシン搭載：** `"\\""` や、エスケープバックスラッシュが奇数・偶数個入り乱れる難解なQMKエスケープでも、データの値を絶対に壊さず外側だけに確実にスペースを制御する完全解析エンジンを搭載。
* **相対コンフリクト同期スクロール：** 左右のコードの行数がマージによってどれだけ上下にズレていようとも、ジャンプした「衝突ヘッダー（黄色い帯）」の位置をアンカー（基準）として記憶。**黄色い帯が真横に綺麗に並んだ美しさを1ピクセルも崩さず左右が完全一体となって連動スクロール**します（デフォルトON）。
* **ダイナミック・ブロックワープ：** 1行ずつチマチマ動くのではなく、変更の「塊（ブロック）」ごとに一気にページをめくるように滑らかにワープジャンプ。
* **EditBox数値直接ワープ：** 前後ボタンだけでなく、入力欄に直接「10」と打ち込んでエンターを押すだけで目的の衝突箇所へサクッとワープ（未選択状態の「0」番リセット機能 ＆ 最大数自動ロックガード付き）。
* **フォーカスハイライト ＆ 最適視野：** ジャンプした変更ブロック全体がフワッと優しい黄色で包み込まれるように強調表示。展開ボタンや圧縮ボタンを押した際も、ボタンを見失わないブラウザの最適な視野位置まで自動スムーズスクロールします。

## 💻 使い方

1. [公開されているWebサイト](https://karbou12.github.io/qmk-json-tool/)にアクセスします。
2. 上部のタブから使いたいツールを選択します。
3. テキストエリアに対象のコードやJSONを貼り付け、実行ボタンを押すだけです。

## 🔒 セキュリティとプライバシーについて

このツールは **100%クライアントサイド（お使いのブラウザ上）** で動作します。
貼り付けられたソースコードやJSONデータ、機密情報が外部のサーバーに送信されることは一切ありません。完全オフライン環境でも安心してご利用いただけます。

## 📂 オフライン環境での使い方（ローカル ＆ デプロイ）

本リポジトリの `index.html` をパソコンにダウンロードし、ブラウザ（Chrome等）にドラッグ＆ドロップするだけで**ローカルの完全オフライン環境**ですべての機能が動作します。

```bash
# ローカルで試す場合
git clone https://github.com/karbou12/qmk-json-tool/
cd リポジトリ名
open index.html
```
